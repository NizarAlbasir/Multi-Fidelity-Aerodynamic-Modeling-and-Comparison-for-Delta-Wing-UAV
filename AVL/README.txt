How to use:
-Set up the .avl and .mass files as usual.
-Add the run cases into "avl_run_files" folder. (make sure that each run file contains no more than 25 case).
-Run "avl_batch_runner.m". (it will creat the folder "VAB" that contains all the derivatives with the ending "ST").
-Run "parse_avl_all_ST.m". (This script creat both matlab and excel files that contains all the data).

*NOT: the AVL source code should exist in the same Folder (AVL).
